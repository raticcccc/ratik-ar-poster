# Poster Skies (WebAR)
Static site: index.html + lib/ + assets/poster.mind (compiled tracking target for assets/poster.jpg).
Deploy: push this folder's contents to a GitHub repo -> Settings -> Pages -> Deploy from branch (main, / root).
Open the https://<user>.github.io/<repo>/ link on a phone, tap Start, allow camera, point at the poster.
Edit CRITTERS (flock) and NODES (info text) at the top of the script in index.html.
